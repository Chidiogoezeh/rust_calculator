# Rust CLI Calculator

A simple command-line calculator built with **Rust** as part of my Rust learning journey.

The project demonstrates basic Rust concepts such as:

- Variables and mutability
- Functions
- Data types
- User input
- Parsing input
- `match` expressions
- Loops
- Error handling
- Basic control flow

## Features

The calculator supports:

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

It also validates user input and prevents division by zero.

## Requirements

- Rust
- Cargo

You can verify your installation with:

```bash
rustc --version
cargo --version
```

## Getting Started

Clone the repository and navigate into the project:

```bash
git clone <https://github.com/Chidiogoezeh/rust_calculator >
cd <project-folder>
```

Run the calculator:

```bash
cargo run
```

## Example

```text
==Rust Calculator==

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit

Choose an operation:
1

Enter first number:
10

Enter second number:
5

Result: 15
```
